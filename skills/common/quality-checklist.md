# BitWorld 集团产出质量自检清单

## 使用方法

每次生成报告或简报后，在产出末尾附上以下自检结果。逐项检查，通过的打 `[x]`，不通过的打 `[ ]` 并自行修正后再提交。

## 自检项

```
---
## 质量自检
- [ ] 标题和日期时间戳完整
- [ ] 执行摘要不超过 5 句话且包含核心数字
- [ ] 所有数据引用标注了来源和时间
- [ ] 无"暂无数据""待补充"等占位内容
- [ ] 字数达到要求范围（早晚报 5000-8000 / 临时 1500-3000）
- [ ] 所有链接为真实可访问 URL
- [ ] 关键要点总结覆盖每个主要章节
- [ ] 使用简体中文 + 英文专有名词混合
- [ ] 数字格式统一（$千分位、百分比一位小数、北京时间）
```

## 注意

如果有任何一项不通过，Agent 应自行修正后再提交，而非直接提交不合格产出。
