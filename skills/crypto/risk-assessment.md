# 风险评估框架

## 实时风险监控维度

### 价格风险
- BTC 24h 波动率 > 5% → 🟡 关注
- BTC 24h 波动率 > 10% → 🔴 警告
- 单小时跌幅 > 5% → ⚫ 紧急

### 杠杆风险
- 全网合约清算额 1h > $100M → 🟡 关注
- 全网合约清算额 1h > $500M → 🔴 警告
- 单一交易所异常清算 → ⚫ 紧急

### 流动性风险
- 稳定币脱锚 > 0.5% → 🟡 关注
- 稳定币脱锚 > 2% → 🔴 警告
- 主要 DEX 滑点异常飙升 → 🔴 警告

### 交易所风险
- 主要交易所异常提币激增 → 🟡 关注
- 交易所暂停提币 → 🔴 警告
- 交易所疑似资不抵债 → ⚫ 紧急

### 监管风险
- 突发性执法行动或政策声明 → 🔴 警告
- 主要经济体全面禁令 → ⚫ 紧急

## 风险等级定义

| 等级 | 图标 | 含义 | 行动 |
|------|------|------|------|
| 正常 | 🟢 | 各指标在正常范围内 | 常规监控 |
| 关注 | 🟡 | 某项指标接近阈值 | 加密关注，准备预案 |
| 警告 | 🔴 | 触发预警条件 | 通知事业部 CEO 和集团 CEO |
| 紧急 | ⚫ | 极端风险事件 | 绕过汇报链直接通知董事长 |

## 预警消息格式（发送至 Telegram）

```
⚠️ [🔴 警告] [价格风险]
事件：BTC 1 小时内下跌 7.2%
当前值：$62,180（1h 前 $67,010）
阈值：1h 跌幅 > 5%
全网清算：$234M（多单 $198M / 空单 $36M）
建议：降低杠杆仓位，关注 $60,000 关键支撑
```

