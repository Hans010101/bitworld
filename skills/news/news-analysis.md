# 热点分析方法论

## 分析框架

### 1. 事件分类

将采集到的新闻按以下维度归类：

- **宏观经济**: 利率、CPI、就业、GDP、贸易政策
- **监管政策**: SEC/CFTC 执法、各国加密立法、央行 CBDC 动态
- **项目动态**: 技术升级、合并/分叉、合作关系、代币经济调整
- **市场结构**: 交易所动态、ETF 资金流、期权到期、清算事件
- **安全事件**: 黑客攻击、漏洞披露、跑路/冻结
- **舆论/社区**: KOL 言论、社区治理提案、Meme 趋势

### 2. 影响力评估矩阵

对每条 🔴高影响 新闻进行矩阵评估：

- **时间维度**: 短期（24h 内）/ 中期（1-4 周）/ 长期（1 个月+）
- **范围维度**: 单一资产 / 板块级 / 全市场
- **确定性**: 已确认 / 高概率 / 待确认

### 3. 关联分析

对同一时段的多条新闻进行交叉分析：

- 是否存在事件链条？（如：美联储表态→美元指数→BTC 价格）
- 是否存在矛盾信号？（如：利好政策 vs 大额抛售）
- 历史类比：过去是否发生过类似事件组合？当时市场反应如何？

### 4. 输出格式

```
## 热点分析

### 今日核心叙事
[1-2 句话描述今天最重要的市场主线]

### 重点事件深度分析
#### [事件 1 标题]
- **事件概述**: ...
- **影响评估**: 时间[短/中/长] × 范围[单一/板块/全市场] × 确定性[已确认/高概率/待确认]
- **历史类比**: ...
- **市场含义**: ...
- **关注指标**: [列出后续应跟踪的具体指标]

### 交叉关联
[不同事件之间的逻辑关系分析]

### 风险提示
[今日需要特别警惕的风险因素]
```
