# 数据分析方法论

## 数据获取优先级

| 优先级 | 获取方式 | 示例 | 可信度 |
|--------|---------|------|--------|
| P0 | API 自动获取 | CoinGecko API、DefiLlama API | 最高 |
| P1 | 官方报告引用 | 项目方季报、交易所透明度报告 | 高 |
| P2 | 第三方聚合平台 | Messari、Token Terminal 页面数据 | 中高 |
| P3 | 媒体报道引用 | Bloomberg、CoinDesk 文中数据 | 中（需交叉验证）|

## 数据清洗检查项

1. **缺失值处理**：标注缺失范围，说明是否影响结论，必要时用插值或注明 N/A
2. **异常值识别**：超出均值 ±3σ 的数据点标注并说明原因（真实异常 vs 数据错误）
3. **时区统一**：所有时间转换为北京时间 CST，原始数据时区在脚注标注
4. **单位统一**：金额统一为 USD，大数用 K/M/B/T 缩写（$1.5B），百分比保留一位小数

## 可视化建议

由于产出为 Markdown，用表格代替图表：

| 数据类型 | 推荐呈现方式 | 示例 |
|----------|-------------|------|
| 时间序列 | 折线描述 + 关键节点表格 | "BTC 价格从 $60K 上涨至 $67K，3/15 突破 $65K 阻力" |
| 对比数据 | 并列表格 | 多列对比表（项目A vs B vs C）|
| 分布数据 | 百分比表格 + 文字柱状图 | "DeFi TVL 分布：ETH 58% ████████ SOL 12% ██" |
| 排名数据 | 排序表格 | Top 10 排名，含变化箭头 ↑↓→ |

## 数据引注格式

每个数据表格底部附注：

```
> 数据源：CoinGecko API | 获取时间：2026-03-23 08:00 CST | 数据范围：2026-03-16 ~ 2026-03-23 | 更新频率：实时
```
