# 数据分析方法论

## 数据获取优先级

| 优先级 | 获取方式 | 示例 | 可信度 |
|--------|---------|------|--------|
| P0 | API 自动获取 | CoinGecko API、DefiLlama API | 最高 |
| P1 | 官方报告引用 | 项目方季报、交易所透明度报告 | 高 |
| P2 | 第三方聚合平台 | Messari、Token Terminal 页面数据 | 中高 |
| P3 | 媒体报道引用 | Bloomberg、CoinDesk 文中数据 | 中（需交叉验证）|

## 数据清洗检查项

1. **缺失值处理**：标注缺失范围，说明是否影响结论，必要时用插值或注明 N/A
2. **异常值识别**：超出均值 ±3σ 的数据点标注并说明原因（真实异常 vs 数据错误）
3. **时区统一**：所有时间转换为北京时间 CST，原始数据时区在脚注标注
4. **单位统一**：金额统一为 USD，大数用 K/M/B/T 缩写（$1.5B），百分比保留一位小数

## 可视化建议

由于产出为 Markdown，用表格代替图表：

| 数据类型 | 推荐呈现方式 | 示例 |
|----------|-------------|------|
| 时间序列 | 折线描述 + 关键节点表格 | "BTC 价格从 $60K 上涨至 $67K，3/15 突破 $65K 阻力" |
| 对比数据 | 并列表格 | 多列对比表（项目A vs B vs C）|
| 分布数据 | 百分比表格 + 文字柱状图 | "DeFi TVL 分布：ETH 58% ████████ SOL 12% ██" |
| 排名数据 | 排序表格 | Top 10 排名，含变化箭头 ↑↓→ |

## 数据引注格式

每个数据表格底部附注：

```
> 数据源：CoinGecko API | 获取时间：2026-03-23 08:00 CST | 数据范围：2026-03-16 ~ 2026-03-23 | 更新频率：实时
```

## 输出格式禁令(Phase 5b 批 2 / Hotfix-v9)

报告 markdown 必须严格遵守。Code 在 PDF 渲染前会预处理剥离这些字段(server/src/services/openai-post-run.ts:stripReportMetadata),但仍**禁止 Agent 输出**——双层防御。

### 禁止输出(头部噪音)
- ❌ `[董事长指令] ...` 前缀(不复述用户原指令)
- ❌ `**报告编号**: XXX`
- ❌ `**报告生成时间**: XXX`(时间已在 📅 顶部 metadata)
- ❌ `**数据窗口**: XXX`
- ❌ `**报告负责人**: XXX`
- ❌ `**数据来源**: XXX(状态码 / 响应时间)`(数据 inline 引用来源即可)
- ❌ 与 PDF 大标题重复的独立 H1(大标题由 Code 用 `📌 主题 | YYYY-MM-DD` 自动生成)

### 禁止输出(尾部)
- ❌ `--- 报告结束 ---` / `## 报告结束` / `**报告结束**`
- ❌ "四、数据质量说明" 整节(数据可靠性逐项 inline 标注)
- ❌ "免责声明" / "本报告由 AI 生成" 类样板

### 必填顶部 2 行
- ✅ `📌 主题: <简短主题,≤25 字,不含日期>`
- ✅ `📅 时间: YYYY-MM-DD`

### 表格规范
- 标准 markdown table:`| 列 | 列 |` + 分隔行 `|---|---|`
- Code 自动解析为 PDF 网格(renderTable)
- 不用 ASCII 艺术对齐(变宽字体下错位)

### 强调规范
- 加粗用 `**xxx**`,Code 自动剥离 markers(CJK 字体无 bold variant,visually 与正文同)
- 斜体用 `*xxx*`,同样剥离 markers
- 行内代码用 backtick `` `xxx` ``,同样剥离 markers
- 不用 `_xxx_` 下划线变体(Agent LLM 输出不稳定)

### 列表 / 序号
- 无序:`- xxx` 或 `* xxx`,Code 渲染为 `•` 项目符号
- 有序:`1. xxx` `2. xxx`,Code 保留数字 prefix
- 不用 `☐` / `▢` / `□` 等不常见 box-drawing 符号(CJK 字体可能缺字)

### 项目简介(每个具体项目 1-2 句)
- GitHub repo / 加密币种 / 新闻条目 / 舆情事件 / 公司:**功能 + 解决的问题**
- 条目 < 5:全部详细
- 条目 ≥ 10:Top 5 详细,其余 1 行简述
