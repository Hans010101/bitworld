# 研究方法论

## 研究流程

```
选题 → 文献扫描 → 数据采集 → 分析 → 初稿 → 审核 → 定稿
```

| 阶段 | 负责人 | 产出 | 时间预估 |
|------|--------|------|---------|
| 选题 | CEO | 选题确认单 | — |
| 文献扫描 | 写手 | 参考文献列表 (≥10篇) | — |
| 数据采集 | 数据分析师 | 结构化数据表 | — |
| 分析 | 写手 | 分析框架 + 初步结论 | — |
| 初稿 | 写手 | 完整 Markdown 报告 | — |
| 审核 | 主编 | 审核意见 + 修改标注 | — |
| 定稿 | CEO | 终版报告 | — |

## 选题标准

| 维度 | 权重 | 评分标准 |
|------|------|---------|
| 市场关注度 | 30% | 近 7 天社媒讨论热度、搜索趋势 |
| 数据可获得性 | 25% | 是否有可靠的 T1 数据源支撑 |
| 时效性 | 25% | 是否在事件窗口期内，读者需要即时了解 |
| 读者价值 | 20% | 对投资决策/行业理解的实际帮助 |

## 分析框架（根据题目选用）

### 框架 A：项目分析
1. 团队背景（创始人履历、融资历史、投资方）
2. 技术架构（共识机制、创新点、技术风险）
3. 代币经济（分配方案、解锁时间表、通胀/通缩机制）
4. 竞品对比（功能矩阵、TVL/用户对比、差异化优势）
5. 风险评估（技术风险、监管风险、市场风险）
6. 估值分析（P/S、P/TVL、同赛道对标）

### 框架 B：赛道分析
1. 市场规模（TAM/SAM/SOM，增长率预测）
2. 竞争格局（市场份额、护城河、新进入者威胁）
3. 技术趋势（关键技术演进路线、瓶颈与突破）
4. 投资逻辑（价值驱动因素、催化剂、时间窗口）
5. 风险（监管、技术、市场周期）

### 框架 C：事件分析
1. 事件背景（时间线、关键人物、前因后果）
2. 各方立场（利益相关方诉求和博弈）
3. 历史对比（类似事件的市场反应）
4. 影响预测（短期/中期/长期，分情景分析）
5. 投资启示（操作建议、关注指标）

## 数据要求

- 每篇报告至少引用 5 个 T1 来源（参见 source-citation.md）
- 至少包含 10 个以上独立数据点
- 所有数据标注采集时间和来源

## 输出格式禁令(Phase 5b 批 2 / Hotfix-v9)

报告 markdown 必须严格遵守。Code 在 PDF 渲染前会预处理剥离这些字段(server/src/services/openai-post-run.ts:stripReportMetadata),但仍**禁止 Agent 输出**——双层防御。

### 禁止输出(头部噪音)
- ❌ `[董事长指令] ...` 前缀(不复述用户原指令)
- ❌ `**报告编号**: XXX`
- ❌ `**报告生成时间**: XXX`(时间已在 📅 顶部 metadata)
- ❌ `**数据窗口**: XXX`
- ❌ `**报告负责人**: XXX`
- ❌ `**数据来源**: XXX(状态码 / 响应时间)`(数据 inline 引用来源即可)
- ❌ 与 PDF 大标题重复的独立 H1(大标题由 Code 用 `📌 主题 | YYYY-MM-DD` 自动生成)

### 禁止输出(尾部)
- ❌ `--- 报告结束 ---` / `## 报告结束` / `**报告结束**`
- ❌ "四、数据质量说明" 整节(数据可靠性逐项 inline 标注)
- ❌ "免责声明" / "本报告由 AI 生成" 类样板

### 必填顶部 2 行
- ✅ `📌 主题: <简短主题,≤25 字,不含日期>`
- ✅ `📅 时间: YYYY-MM-DD`

### 表格规范
- 标准 markdown table:`| 列 | 列 |` + 分隔行 `|---|---|`
- Code 自动解析为 PDF 网格(renderTable)
- 不用 ASCII 艺术对齐(变宽字体下错位)

### 强调规范
- 加粗用 `**xxx**`,Code 自动剥离 markers(CJK 字体无 bold variant,visually 与正文同)
- 斜体用 `*xxx*`,同样剥离 markers
- 行内代码用 backtick `` `xxx` ``,同样剥离 markers
- 不用 `_xxx_` 下划线变体(Agent LLM 输出不稳定)

### 列表 / 序号
- 无序:`- xxx` 或 `* xxx`,Code 渲染为 `•` 项目符号
- 有序:`1. xxx` `2. xxx`,Code 保留数字 prefix
- 不用 `☐` / `▢` / `□` 等不常见 box-drawing 符号(CJK 字体可能缺字)

### 项目简介(每个具体项目 1-2 句)
- GitHub repo / 加密币种 / 新闻条目 / 舆情事件 / 公司:**功能 + 解决的问题**
- 条目 < 5:全部详细
- 条目 ≥ 10:Top 5 详细,其余 1 行简述
