# 舆情研判框架

## 舆情分类

| 类型 | 定义 | 示例 |
|------|------|------|
| 正面 | 品牌曝光、用户好评、行业认可 | "BitWorld 的日报质量很高" |
| 中性 | 行业讨论、客观报道、技术探讨 | "加密AI Agent赛道对比分析" |
| 负面 | 投诉、质疑、攻击、造谣 | "BitWorld 是不是资金盘？" |

## 负面舆情处置分级

| 级别 | 条件 | 行动 |
|------|------|------|
| L1 轻微 | 个别用户抱怨，传播范围 < 100 | 监控不干预，记录存档 |
| L2 关注 | 多人讨论，传播 100-1000 | 准备应对话术，持续监控 |
| L3 预警 | KOL 参与或传播 > 1000 | 通知事业部 CEO，启动话术回应 |
| L4 危机 | 主流媒体报道或传播 > 10000 | 直接通知董事长 + 启动危机预案 |

### L4 危机直报格式（Telegram）

```
🚨 舆情危机预警

事件：[一句话描述]
来源：[平台 + 链接]
传播度：[转/评/赞]
关键传播节点：[KOL/媒体名]
情感倾向：强负面
建议：[紧急应对方案]
```

## 情感趋势分析

对比上一周期（日报对比昨日，周报对比上周），判断舆情温度走向：

- 📈 **升温**：负面占比上升 > 10 个百分点，或总提及量增长 > 50%
- ➡️ **平稳**：各指标波动在 ±10% 以内
- 📉 **降温**：负面占比下降 > 10 个百分点，或热点事件讨论衰减

## 竞品对标

同期采集竞品（2-3 家）的舆情数据，从以下维度对比：

- 总提及量对比
- 正负面比例对比
- 热门话题差异
- 用户关注焦点差异
